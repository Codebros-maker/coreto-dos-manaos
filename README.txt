Estrutura:

COMO PUBLICAR NA VERCEL
1. Entre na Vercel e selecione "Add New" > "Project".
2. Envie esta pasta via GitHub (ou use a Vercel CLI nesta pasta).
3. Framework: "Other". Build Command: vazio. Output Directory: vazio.
4. Publicação estática automática: index.html é a página inicial.
5. Crie um projeto Vercel diferente para cada restaurante.

IMPORTANTE ANTES DE ENVIAR AOS CLIENTES
- Protótipo INDEPENDENTE e NÃO OFICIAL, sem vínculo ou autorização do negócio.
- Fotografias são ILUSTRATIVAS e carregadas por URLs externas do Unsplash; a capa possui também uma ilustração local de fallback.
- Textos e itens de cardápio NÃO são um cardápio oficial/atualizado.
- NÃO há funcionalidade de pedido/reserva, checkout, administração ou banco de dados.
- Revise endereço, horários, nomes, domínios, fotos e contato diretamente com o cliente.
- A tag noindex evita que a demonstração seja tratada como site oficial por buscadores.
- Antes de publicar como site oficial, obtenha autorização e arquivos de marca/fotos próprios.

Solução técnica: HTML, CSS e JS puros, sem instalação de pacotes.
